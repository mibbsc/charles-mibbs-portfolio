# Charles Mibbs — Personal Portfolio Website

A responsive multi-page portfolio site built with plain HTML, CSS, and JavaScript. No build tools or framework required.

## Pages
- `index.html` — home page with LinkedIn, Credly, email, and calls to action
- `about.html` — drafted About Me page based on Charles's transition from Army infantry to cloud/network engineering
- `resume.html` — professional resume draft; use **Print / Save PDF** to create a PDF
- `portfolio.html` — project cards that link to the public Notion portfolio
- `styles.css` — responsive styling, animated ambient background, and network/cloud visuals
- `script.js` — navigation and link behavior
- `config.js` — name, email, LinkedIn, Credly, and Notion URLs

## Before publishing
1. Review the About and Resume pages carefully for accuracy.
2. Add verified certifications, project outcomes, dates, and measurable accomplishments as they become available. Do not list a certification until it has been earned.
3. Check that the Notion pages you want employers to see are public. Keep private notes and personal data out of public pages.
4. Open `index.html` in a browser to preview the site.

## Publish with your Porkbun domain
The easiest beginner route is to host the static files on GitHub Pages or Netlify, then connect your Porkbun domain to that host. Upload all files while preserving their names and folder structure. Follow the hosting provider's current custom-domain instructions, then update DNS records in Porkbun exactly as instructed by that provider. DNS changes can take time to propagate. Enable HTTPS in the hosting provider's settings.

Do not paste private credentials, passwords, or API keys into public code.
